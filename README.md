# Teen Lifestyle Planner

A front-end web application designed to help teenagers manage their study time, breaks, and daily routine.

## 🚀 Features
- Study schedule management
- Break & lunch planner
- Daily routine tracking
- Simple and responsive design

## 🛠️ Tech Stack
- HTML
- CSS
- Javascript 

## 💡 Purpose
To promote productivity and a healthy lifestyle among students.
